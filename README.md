## 🎮 About the Game

Ultrapool is a colorful single-player pool roguelike developed by Icedrop Games and published by offbrand games. It released on August 24, 2026. The game combines arcade billiards, roguelite progression, strategy, and deckbuilding as players assemble balls with unusual effects, pocket them for score, spend earnings at the bar, and try to survive ten rounds.

## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Ultrapool**. This trainer provides optional quality-of-life and progression controls for Ultrapool. It can adjust scoring, money earned between rounds, run progression, and selected ball-build resources while preserving the game's core aiming, shooting, pocketing, and ball-effect mechanics.

**Target Audience:** Players who want to experiment with ball synergies, practice trickshots, explore the bar's upgrade choices, or reduce the difficulty of roguelite runs.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Ultrapool is played from a pool-table view and does not use character movement. Aim the cue, adjust shot power, and take shots normally while the trainer runs in the background.

### Tools & Inventory

The game's main build consists of collected and upgraded balls with distinct effects. Use the trainer's build-support option only after entering a run, then manage purchases and ball choices through the normal bar interface.

### World & Environment

Ultrapool's progression takes place across pool rounds and bar encounters rather than an explorable world. Earn score by pocketing balls, convert score into money, and spend it on new or improved balls between rounds.

### Combat & Weapons

Ultrapool has no combat system. Its primary challenge is executing pool shots, combining ball effects, maximizing score, and surviving the run's ten rounds.
